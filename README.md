# Personal-Game-Manager

A user will be able to browse and search for games, filter them, and add them into their own personal library in which they can sort and make notes on each game

## Features

- Search bar
- Popular games tab
- Add games based on status (playing, completed, wishlist)
- Remove games
- Filter games by categories
- Sort games by rating and alphabetical order
- Favorite games
- Rate games
- Personal notes
- View games on Steam
- Data persists

## Technologies

- HTML
- CSS
- JavaScript
- CheapSharkAPI
- Local storage

## How It Works

The project retrieves game information through CheapShark, allowing users to interact with them. Games added to the library are saved in local storage so that the data persists between sessions.

## How to Use

1. Clone the repo
2. Open index.html in a web browser
